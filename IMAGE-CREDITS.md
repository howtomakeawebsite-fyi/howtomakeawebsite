# Image and font credits

Every picture in this template was drawn for it as simple shapes (SVG). No photographs, no pictures of real people and no stock images are used. You may use, change or replace all of them.

| File | What it is | Source |
|---|---|---|
| `public/brand/logo-mark.svg` | Sample logo: sun rising over two hills | Original drawing made for this template |
| `public/brand/icon-maskable.svg` | Same logo with extra space around it, for Android app icons | Original drawing made for this template |
| `public/images/hero-valley.svg` | Home page banner: a valley at sunrise with a small church | Original drawing made for this template |
| `public/images/sermon-placeholder.svg` | Sample video thumbnail with a play button | Original drawing made for this template |
| `public/images/map-placeholder.svg` | Sample map shown until a real address is set | Original drawing made for this template |
| `public/images/avatar.svg` | Sample person outline used when a team member has no photo | Original drawing made for this template |
| `public/images/og-card.svg` | Picture shown when a link to the site is shared | Original drawing made for this template |
| `public/icons/icon-192.png`, `icon-512.png`, `maskable-512.png` | App icons | Made from the logo drawings by `npm run icons` |
| `src/app/icon.png`, `src/app/apple-icon.png` | Browser tab icon and iPhone icon | Made from `logo-mark.svg` by `npm run icons` |
| `src/app/opengraph-image.png`, `public/opengraph-image.png` | Share picture | Made from `og-card.svg` by `npm run icons` |

The small line icons (clock, map pin and so on) are drawn in code in `src/components/Icon.tsx`.

## When you add your own pictures

- Only use photos you took yourself, or have written permission to use, or that come from a free-licence source. Write each one down in this file with where it came from.
- Ask people before you publish a photo they are in. Take extra care with children.
